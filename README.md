# Buzz Bingo mobile tester downloads

Public Android APK downloads for invited Buzz Bingo mobile prototype testers.

Canonical direct Android download:

https://buzz-bingo-mobile-testers.vercel.app/tester-guide/buzz-bingo-android-arm64.apk

GitHub release archive and fallback:

https://github.com/JanarDot/buzz-bingo-mobile-downloads/releases/latest/download/buzz-bingo-android-arm64.apk

Every published release and tester-site deployment must keep the asset filename `buzz-bingo-android-arm64.apk`. The direct tester-site URL is the link used in Buzz Bingo browser surfaces and guides.
